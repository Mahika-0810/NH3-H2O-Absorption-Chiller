# Model development and correction log

This package contains an ammonia–water absorption-chiller model organized around state points, component balances, property correlations, and operating-feasibility checks. It is a screening model and is not an independently validated equipment-design model.

## Thermodynamic model updates (13 Oct 2026)

- Generator-top vapour equilibrium uses the incoming strong solution (`x_strong`, state 5) to calculate `Ttop` and `y_eq`. The generator outlet temperature and enthalpy use the weak solution (`x_weak`, state 8).
- Clarified species-wise enthalpy-reference offsets. The ammonia offset anchors the Patek–Klomfar pure-ammonia saturated-vapour enthalpy to the Peng–Robinson EOS saturated-vapour value at 273.15 K; it is not an ideal-gas-zero convention. Water uses a constant liquid-water offset. The offsets cancel in balances only with closed species balances.
- Added direct tests for generator equilibrium and component balances.
- Regenerated state-point, seasonal, 40%-fresh-air, condenser-feasibility, plot, and balance outputs.
- Added one-at-a-time sensitivity studies for solution density, flue-gas heat capacity, generator/flue heat-exchanger effectiveness, and condenser UA/flow exponent.

## Validation status

- Automated tests are included in `tests/`.
- The full `python main.py` workflow regenerates outputs and runs the programmed engineering checks.
- Checks labelled `Review` identify assumptions or plausibility concerns and should not be treated as passes.
- Density, condenser UA/flow scaling, and flue-gas properties remain assumption-based and require vendor/plant data for final engineering design.

No presentation files are generated by the Python workflow.
